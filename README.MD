# Photomic Battery Pack
The goal of this project is to create a lipo replacement pack for the Nikon F FTn lightmeter.

## Lightmeter requirements
- Input: Constant 2.7V 
- Current draw: 0.00015A (according to repair manual)

## Battery Pack parts
- Type C input
- Small Lipo Pack (BMS integrated)
- Voltage output regulator
- Housing
